# AOP Source Errata (Concept Scope)

Informative. This document records where the programme owner's original source documents differ from the ratified estate, so a reader arriving from the sources is oriented and the sources are not silently rewritten. The ratified estate is authoritative; the sources remain the lineage.

| # | Source | Source wording | Estate position | Disposition |
|---|---|---|---|---|
| 1 | Agentic Operating Procedures Exec Summary | Lists six dimensions (Intent, Context, Authority, Capabilities, Constraints, Assurance) | Eight dimensions are normative (NM-MODEL-1): Coordination and Control complete the octet | Superseded. The executive summary's list predates the ratification; the eight-dimension model governs |
| 2 | From SOP to AOP (framing paper) | "An SOP rewritten (or newly designed) so an AI agent can execute it reliably and safely" | The AOP is compiled from observed work, not a rewrite; the concept model's four structural distinctions govern | Superseded wording. The framing paper's later sections (the observe, model, compile, execute pipeline) carry the ratified position; the rewrite sentence is legacy |
| 3 | AOP Intro | "AOP is not an Agent Harness" alongside the framing paper's "the harness is the top-level AOP for that domain" | The harness is specified as its own top-level AOP (SEC-11): the harness is a runtime boundary governed by an AOP it carries; the two statements are reconciled as boundary-versus-specification | Reconciled normatively. The source statements are two views of the SEC-11 relationship |
| 4 | Framing paper vs AOP Intro on authoring | "cannot be authored from imagination; compiled from observation" versus authored via the six-stage process | Authority-bearing rules require observed provenance and ratification (NM-PRV-3, NM-AUT-7); authored intent hypotheses are the tested claims (NM-INT-3) | Reconciled normatively. Authored intent is the hypothesis; observed, ratified rules are the standard |
| 5 | Staged metamodel documents | The Assumed stage-to-entity ranges in early estate working notes (for example, Stage 02 = E09 to E20) | The documents' own registers govern: Stage 02 = E01 to E14, Stage 04 = E15 to E25, Stage 06 = E41 to E60; E26 to E40 unpinned | Superseded working assumption. The metamodel entity register is the authority on ranges |

The errata exist so the sources can be read without confusion and without editing them. Where a reader finds a discrepancy not listed here, it is a finding against `aop-governance`.
